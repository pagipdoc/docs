## Behavior and handling

Get details for a specific infraction report. Check the associated report, case, and original transaction.

## Permissions and account ownership

ACCOUNT, or USER with both `X-ISPB` and `X-Account-Number` for an account owned by that USER. PLATFORM credentials are not supported. ACCOUNT credentials use their bound account; if target headers are sent, both must be nonempty and match that account. The infraction report must be associated with a transaction received by the selected account. <Badge color="blue" size="sm">Added · api-22-F05</Badge> Requests must follow [Environments & Credentials](/environments-and-credentials).

## Request parameters

<ParamField body="infraction_id" type="string" required>
Infraction record ID from `data.items[].infraction_id` in the list response. Use this value exactly; it is distinct from `infraction_report_id` and `dict_infraction_report_id`. <Badge color="blue" size="sm">Added · api-22-F06</Badge>
</ParamField>

<Info>
**Parameter sources**

`infraction_id` comes from `data.items[].infraction_id` in a successful response from [List infraction reports](/api-reference/med/list-infraction-reports) (`/v3/infractions/list`).
</Info>
