## Funcionamento e tratamento

Consulte a lista de contas gerenciadas visíveis para o USER atual. É possível filtrar por modelo de conta, status ou CPF/CNPJ e paginar os resultados. Os filtros por modelo e status são aplicados antes da paginação. Os filtros por CPF/CNPJ e visibilidade das contas são aplicados depois, à página selecionada. Por isso, uma página pode conter menos contas que `page_size` ou estar vazia mesmo quando há correspondências em outras páginas. Os totais de paginação correspondem aos registros anteriores a esses últimos filtros; não encerre a paginação apenas porque `managed_accounts` está vazio. <Badge color="blue" size="sm">Complementado · api-38-F07</Badge>

## Permissões e titularidade da conta

USER, sem os headers `X-ISPB` ou `X-Account-Number`, inclusive headers explicitamente vazios. O USER deve ter exatamente uma conta master com status `ACTIVE` e dados bancários correspondentes a uma conta bancária com status `ACTIVE`; caso contrário, a requisição retorna o `code` de negócio `4004003` (Permission denied). MOR e VA devem pertencer diretamente a essa conta master. A PA deve pertencer a essa conta master ou a uma VA com status `ACTIVE` diretamente vinculada a ela. A conta bancária da conta superior direta também deve ter status `ACTIVE` e dados correspondentes. <Badge color="blue" size="sm">Complementado · api-38-F06</Badge> As requisições devem seguir as orientações de [Ambientes e credenciais](/pt-br/environments-and-credentials).

## Parâmetros da requisição

Todos os parâmetros são opcionais. Omita os campos de filtro para não filtrar. É possível informar apenas page para paginação.

<ParamField body="model" type="integer">
**Obrigatório:** Não (não obrigatório nesta camada). Modelo de conta gerenciada. Valores: `1` MOR; `2` VA; `3` PA. Omita este campo para não filtrar por modelo. O valor `0` informado explicitamente ou qualquer outro valor retorna o `code` de negócio `4001` (Invalid model value). <Badge color="blue" size="sm">Complementado · api-38-F03</Badge>
</ParamField>

<ParamField body="status" type="integer">
**Obrigatório:** Não (não obrigatório nesta camada). Filtro de status da conta gerenciada. Valores: `1` PENDING; `2` ACTIVE; `3` FROZEN; `4` CLOSED; `5` REJECTED; `6` EXPIRED. Omita este campo para não filtrar por status. Os valores `0` e `7` e quaisquer outros valores retornam o `code` de negócio `4001` (Invalid status value). <Badge color="blue" size="sm">Complementado · api-38-F04</Badge>
</ParamField>

<ParamField body="tax_id" type="string">
**Obrigatório:** Não (não obrigatório nesta camada). CPF/CNPJ da pessoa ou empresa. Deve corresponder exatamente ao número do documento de conformidade, sem diferenciar maiúsculas de minúsculas e ignorando espaços nas extremidades. A pontuação do documento não é removida. Um valor vazio ou composto apenas por espaços não aplica filtro por CPF/CNPJ. <Badge color="blue" size="sm">Complementado · api-38-F05</Badge>
</ParamField>

<ParamField body="page" type="object">
**Obrigatório:** Não (não obrigatório nesta camada). Condições de paginação/número da página, diferenciados pelo tipo
</ParamField>

<ParamField body="page.page" type="integer">
↳ **Obrigatório:** Não. Número da página, a partir de 1. Inteiro de 32 bits com sinal, opcional; valores omitidos ou inferiores a 1 usam a página 1. <Badge color="blue" size="sm">Complementado · api-38-F01</Badge>
</ParamField>

<ParamField body="page.page_size" type="integer">
↳ **Obrigatório:** Não. Tamanho da página. Inteiro de 32 bits com sinal, opcional; valores omitidos ou inferiores a 1 usam 10. Valores acima de 100 são reduzidos para 100. <Badge color="blue" size="sm">Complementado · api-38-F02</Badge>
</ParamField>

</ResponseField>

Descrição do resultado de negócio; em caso de falha, analise esta descrição junto com o campo code para identificar a causa.
</ResponseField>

## Respostas

Consulte os exemplos de resposta pelo `code` de negócio no JSON. Verifique o status HTTP e o code de negócio separadamente. Uma resposta HTTP 200 também pode retornar um erro de negócio. <Badge color="orange" size="sm">Corrigido · api-38-F14</Badge>

| `code` | Significado | Ação recomendada |
| --- | --- | --- |
| `200` | Requisição bem-sucedida | Leia data e avalie o resultado do processamento conforme o status de negócio deste endpoint. |
| `400` | Falha na requisição ou validação | Problema nos parâmetros. Verifique e corrija os parâmetros da requisição. |
| `500` | Erro do sistema | Registre a resposta e confirme primeiro o resultado de negócio. |

Os exemplos ilustram a estrutura da resposta. Os valores de message e do status de negócio devem ser obtidos da resposta efetiva. Para outros erros de parâmetros, permissões e serviço, consulte [Catálogo de erros](/pt-br/api-reference/error-catalog). Esta seção não indica que o endpoint retorna apenas os três valores de code apresentados.
