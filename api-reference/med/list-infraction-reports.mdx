## Behavior and handling

List infraction reports and their associated tasks for transactions received by the authorized target account. Results match the receiving account's ownership, ISPB, and account number. Reports for other accounts in the same MED case are excluded. Results are ordered by creation time, newest first. <Badge color="blue" size="sm">Added · api-21-F01</Badge>

## Permissions and account ownership

Use ACCOUNT credentials for their bound account, or USER credentials with both `X-ISPB` and `X-Account-Number`. The USER must own the target account and its account hierarchy. With ACCOUNT credentials, omit both target-account headers or provide both with values matching the bound account. PLATFORM credentials are not accepted. USER credentials can also query an eligible closed account within the same ownership scope. <Badge color="blue" size="sm">Added · api-21-F02</Badge> Requests must follow [Environments & Credentials](/environments-and-credentials).

## Request parameters

<ParamField body="page" type="integer">
**Required:** No (not enforced at this layer). Page number, starting at 1. Defaults to 1 when omitted or set to 0 or a negative value. <Badge color="blue" size="sm">Added · api-21-F03</Badge>
</ParamField>

<ParamField body="page_size" type="integer">
**Required:** No (not enforced at this layer). Items per page. Defaults to 20 when omitted or set to 0 or a negative value. The query is limited to 100 items per page. Use values from 1 to 100: a larger positive value is still reported in `data.page.page_size`, even though the query uses 100, and `total_pages` is calculated from that reported value. <Badge color="blue" size="sm">Added · api-21-F04</Badge>
</ParamField>

<ParamField body="status" type="integer">
**Required:** No (not enforced at this layer). Filter by infraction task status. Omit this field to include all statuses; supplying 0 filters for `UNSPECIFIED`. Values: 0 `UNSPECIFIED`; 1 `RECEIVED`; 2 `BLOCKING_PENDING`; 3 `BLOCKED`; 4 `ANALYSIS_PENDING`; 5 `CLOSED_AGREED`; 6 `CLOSED_DISAGREED`; 7 `CANCELLED`; 8 `FAILED` <Badge color="blue" size="sm">Added · api-21-F05</Badge>
</ParamField>

<ParamField body="start_time" type="integer">
**Required:** No (not enforced at this layer). Inclusive lower bound for the infraction task's creation time, as a UTC Unix timestamp in milliseconds. Omitted, 0, or negative values do not apply this lower bound. <Badge color="blue" size="sm">Added · api-21-F06</Badge>
</ParamField>

<ParamField body="end_time" type="integer">
**Required:** No (not enforced at this layer). Inclusive upper bound for the infraction task's creation time, as a UTC Unix timestamp in milliseconds. Omitted, 0, or negative values do not apply this upper bound. If both bounds are positive and `start_time` exceeds `end_time`, the query returns no matching records. <Badge color="blue" size="sm">Added · api-21-F07</Badge>
</ParamField>

<ParamField body="case_id" type="string">
**Required:** No (not enforced at this layer). MED case ID
</ParamField>

<ParamField body="infraction_report_id" type="string">
**Required:** No (not enforced at this layer). Provider report ID
</ParamField>

<ParamField body="connected_transaction_id" type="string">
**Required:** No (not enforced at this layer). Associated transaction ID
</ParamField>
