## Behavior and handling

List managed accounts visible to the current USER. You can filter by account model, status, or tax ID and paginate the results. Model and status filters are applied before pagination. Tax-ID and account-visibility filters are applied to the selected page afterward, so a page can contain fewer accounts than `page_size` or be empty even when other pages contain matches. Pagination totals describe the records before these later filters; do not stop pagination solely because `managed_accounts` is empty. <Badge color="blue" size="sm">Added · api-38-F07</Badge>

## Permissions and account ownership

USER, without `X-ISPB` or `X-Account-Number` headers, including explicitly empty headers. The USER must have exactly one `ACTIVE` master account with matching, `ACTIVE` bank account details; otherwise the request returns business code `4004003` (Permission denied). MOR and VA must belong directly to that master account. PA must belong to that master account or to an `ACTIVE` VA directly under it, and its direct parent's bank account must also be `ACTIVE` and match the parent account details. <Badge color="blue" size="sm">Added · api-38-F06</Badge> Requests must follow [Environments & Credentials](/environments-and-credentials).

## Request parameters

All parameters are optional. Omit filter fields to apply no filters. You can provide only page for pagination.

<ParamField body="model" type="integer">
**Required:** No (not enforced at this layer). Managed account model. Values: `1` MOR; `2` VA; `3` PA. Omit this field to apply no model filter. An explicitly supplied `0` or any other value returns business code `4001` (Invalid model value). <Badge color="blue" size="sm">Added · api-38-F03</Badge>
</ParamField>

<ParamField body="status" type="integer">
**Required:** No (not enforced at this layer). Managed account status filter. Values: `1` `PENDING`; `2` `ACTIVE`; `3` `FROZEN`; `4` `CLOSED`; `5` `REJECTED`; `6` `EXPIRED`. Omit this field to apply no status filter. Values `0` and `7`, and all other values, return business code `4001` (Invalid status value). <Badge color="blue" size="sm">Added · api-38-F04</Badge>
</ParamField>

<ParamField body="tax_id" type="string">
**Required:** No (not enforced at this layer). Entity tax ID. Matches the compliance document number exactly, ignoring letter case and leading or trailing whitespace. Document punctuation is not removed. An empty or whitespace-only value applies no tax-ID filter. <Badge color="blue" size="sm">Added · api-38-F05</Badge>
</ParamField>

<ParamField body="page" type="object">
**Required:** No (not enforced at this layer). Pagination conditions/page number, distinguished by type
</ParamField>

<ParamField body="page.page" type="integer">
↳ **Required:** No. Page number, starting at `1`. Optional signed 32-bit integer; omitted values and values below `1` use page `1`. <Badge color="blue" size="sm">Added · api-38-F01</Badge>
</ParamField>

<ParamField body="page.page_size" type="integer">
↳ **Required:** No. Page size. Optional signed 32-bit integer; omitted values and values below `1` use `10`. Values above `100` are reduced to `100`. <Badge color="blue" size="sm">Added · api-38-F02</Badge>
</ParamField>
