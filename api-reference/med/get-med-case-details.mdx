## Behavior and handling

Get MED case details. For a case whose progress is refreshed on query, a failed refresh can still return a successful response with the last recorded case state. Success does not guarantee a fresh status; consider `updated_at` when reconciling progress. <Badge color="blue" size="sm">Added · api-19-F16</Badge> Check case progress, the effective frozen amount, and the returned amount separately.

### Frozen amount, recovered funds, and difference

Record the requested or target freeze amount, effective frozen amount, difference, and returned amount separately. Freezing is a stage of funds processing, not proof that returned funds have been credited. Use the account's MED frozen amount to help reconcile funds. Use case-level details and aggregate amounts to follow the case. This endpoint does not return receiver-side infraction tasks, refund tasks, or funds disposition records, so it cannot identify those individual actions. <Badge color="orange" size="sm">Corrected · api-19-F07</Badge>

### Check case outcomes against return statement entries

Use the MED case ID and, when available, the original transaction ID to link case and funds records. This endpoint does not provide linked infraction report IDs or MED refund task IDs; retain those identifiers only when they are available in your other authorized records. <Badge color="blue" size="sm">Added · api-19-F08</Badge> Check the actual returned amount, target account, and statement entries. Retain case and funds reconciliation records after case closure, and address any shortfall against the target amount.

## Permissions and account ownership

ACCOUNT, or USER with both `X-ISPB` and `X-Account-Number` for an account owned by that user. ACCOUNT credentials are bound to their issued account; if account headers are supplied, both must match that account. PLATFORM credentials are not supported. The MED case must belong to the selected account and its owner; an unknown or out-of-scope case returns business code `4004004`. Requests must follow [Environments & Credentials](/environments-and-credentials). <Badge color="blue" size="sm">Added · api-19-F01</Badge>

</Info>
