## Behavior and handling

Cancel a MED case that is eligible for cancellation. Query the latest details and confirm can_cancel before submitting. Continue checking the case and funds outcomes after cancellation. A successful request does not necessarily mean that final cancellation is complete. Check the returned status and query the latest case details before deciding whether to submit another cancellation request. <Badge color="blue" size="sm">Added · api-20-F03</Badge>

## Permissions and account ownership

ACCOUNT, or USER with both `X-ISPB` and `X-Account-Number` for an account owned by that USER. The MED case must belong to the selected account. With ACCOUNT credentials, omit the account-targeting headers or provide both with values matching the credential-bound account. <Badge color="blue" size="sm">Added · api-20-F01</Badge> Requests must follow [Environments & Credentials](/environments-and-credentials).

## Request parameters

<ParamField body="case_id" type="string" required>
MED case ID from `data.med_case.case_id` in the successful Create MED case response
</ParamField>

<Info>
**Parameter sources**

`case_id` comes from `data.med_case.case_id` in the successful response from [Create MED case](/api-reference/med/create-med-case) (`/v3/med/create`).
</Info>
